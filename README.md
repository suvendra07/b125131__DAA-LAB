## Description

This repository contains the practical file submission for the Design and Analysis of Algorithms (DAA) coursework. The collection encompasses a variety of C programming assignments that explore fundamental algorithmic concepts and their implementations. These assignments include practical demonstrations of algorithm performance, such as analyzing the time complexity of different approaches, comparing expected and actual probabilities through simulation, and understanding the efficiency of classic sorting algorithms under different conditions.

Furthermore, the submission features problem-solving exercises that delve into more complex algorithmic paradigms. This includes implementing solutions for the Towers of Hanoi to observe exponential growth, utilizing binary search techniques to efficiently locate partition points in arrays, and determining element uniqueness by leveraging optimized sorting methods. Together, these implementations serve as a comprehensive practical application of the theoretical concepts discussed during the semester.
